# 聚樂電商圖片資源

此資料夾集中管理聚樂電商 Case Study 的正式圖片。圖片尚未加入時，頁面會使用 JSX mockup，不會顯示破圖。

全域圖片命名：

- `cover.webp` 或 `cover.png`：首頁專案卡片封面
- `hero.webp` 或 `hero.png`：專案頁 hero 背景
- `hero-mobile.webp` 或 `hero-mobile.png`：手機版 hero 圖片
- `hero-visual.webp` 或 `hero-visual.png`：桌機右側 mockup

Section 圖片命名規則：

- 以 section 名稱作為檔名前綴。
- 同一 section 有多張圖時，使用兩位數後綴。
- 同 basename 支援 `.webp` 或 `.png`。

預留檔名：

- `goals-01.webp`：Design Goals preview
- `visual-01.webp`：Visual Direction homepage visual
- `rewards-01.webp`：Rewards & Coupons overview
- `layout-01.webp`：RWD & Bootstrap layout
- `layout-02.webp`：Mobile shopping flow
- `final-01.webp`：Final Design gallery image
- `final-02.webp`：Final Design gallery image
- `final-03.webp`：Final Design gallery image
- `final-04.webp`：Final Design gallery image

圖片路徑由 `src/data/projects/` 底下的 project data 管理。
