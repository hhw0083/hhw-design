# DOME Project Images

Store final image assets for the DOME original animation concept case study in
this folder.

Reserved filenames:

- `cover.webp`: portfolio project listing cover
- `hero.webp`: project detail hero
- `hero-mobile.webp`: optional mobile hero
- `story-concept.webp`: worldbuilding and story concept board
- `visual-direction.webp`: atmosphere, environment, and visual tone board
- `story-01.webp`: story img
- `story-02.webp`: story img
- `character-design-01.webp`: character exploration
- `character-design-02.webp`: character detail or expression exploration
- `final-visual-01.webp`: character and environment final visual
- `final-visual-02.webp`: character and environment final visual
- `final-visual-03.webp`: character and environment final visual
- `final-visual-04.webp`: character and environment final visual

Image paths are managed in the project data files under `src/data/projects/`.
Until a reserved image is added, the case study renders the corresponding
Tailwind fallback visual.
