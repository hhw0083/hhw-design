# INA Waxing Project Images

Store final image assets for the INA Waxing brand website case study in this
folder.

Reserved filenames:

- `cover.webp`: portfolio project listing cover
- `hero.webp`: project detail hero
- `hero-mobile.webp`: optional mobile hero
- `ui-direction.webp`: website structure, service pages, and booking direction
- `visual-extension.webp`: brand visual extension board
- `final-ui-01.webp`: homepage final design
- `final-ui-02.webp`: service detail final design
- `final-ui-03.webp`: mobile booking or responsive final design

Image paths are managed in the project data files under `src/data/projects/`.
Until a reserved image is added, the case study renders the corresponding
Tailwind fallback visual.
